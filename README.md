# 👟 SneakerHead — Sneaker Store

A modern and stylish sneaker showcase website built using **HTML5 and CSS3**. SneakerHead presents a curated collection of sneakers through a clean layout, an engaging hero section, product cards, and a contact form.

## 🌟 Features

- **Modern Landing Page** — Eye-catching hero section with a “Shop Now” call to action.
- **Sneaker Collection** — Showcase of six sneakers with images, names, and descriptions.
- **Navigation Bar** — Quick links to Home, Collection, and Contact Us.
- **Responsive Styling** — CSS-based layout designed for a polished browsing experience.
- **Contact Form** — Form fields for name, email, and message.
- **Image-Rich Design** — Sneaker photography sourced from Unsplash and Pexels.
- **Simple and Lightweight** — Built with HTML and CSS, without requiring a framework.

## 🛠️ Technologies Used

- **HTML5** — Website structure and content.
- **CSS3** — Styling, layout, and visual presentation.
- **Unsplash & Pexels** — External sneaker images.
